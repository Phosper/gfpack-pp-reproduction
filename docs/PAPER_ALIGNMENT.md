# 第五轮：按论文重建推理机制

本轮根据用户要求，将后续工作转为论文推理机制对齐。新增入口与官方源码、旧扩展及四轮历史结果隔离。实现完成不代表论文指标复现成功：公开模型、权重训练配置及测试集身份仍有未解决的差异。

依据为 [论文 v2](https://arxiv.org/html/2406.07579v2) 第4.3、4.4、5.2节及补充材料S2、S3；官方代码固定为 `ff75815e24ec50cd7fa8b2abdec1acfe0b55be95`。作者当前 [README](https://github.com/TimHsue/GFPack-pp/blob/main/README.md) 称碰撞势场已与增强融合；固定快照的实际调用链没有执行该碰撞函数，因此本轮保留调用证据，以实际代码为准。

## 已实现的论文要求

- VE噪声标准差下限0.1、上限1000；高斯先验标准差1000；128次Euler–Maruyama更新。论文配置移除公开采样器的漂移倍率14与额外均匀扰动。
- 在第97–128次更新加入碰撞势场平移项。回调明确返回向外位移场 `C = -grad(Phi)`，按正反向时间步 `g(t)^2 * h * C` 加入；面积权重按式9分配，不额外归一化或裁剪。
- 生成后最多100轮约束与缝隙压缩。保存未收敛状态，拒绝会使原生交叠总量或高度越界变差的压缩移动；这些保护不保证严格几何可行。
- Dental采用48个零件、高1200的水平条带，没有8000宽度的右侧墙。允许整体水平平移，保留真实宽度和利用率损失。
- 将候选可行比例与“样本中至少一个可行候选”的比例分开；保留全部计划候选及运行失败。分别报告官方阈值化几何、float64未阈值化交叠、固定条带边界，以及float32存储后的变化。

## 三种配置的用途

`paper_settings` 使用上述论文数值设置。`paper_mechanism_release_scale` 使用相同高斯先验、漂移倍率1和晚期碰撞机制，但保留发布代码的标准差下限1，用于检查权重配置兼容性。`release_weights_constraints` 保留发布采样器的均匀先验、漂移倍率14、额外扰动与时间网格；本轮对照对它关闭晚期碰撞项，三种配置均使用相同的本轮100轮后处理。

这不是逐项因果消融：先验、漂移、时间网格和约束等因素同时变化。相同seed只形成新的成对配置探针；它在模型初始化后重置，不能与历史基线宣称逐位相同。模型保持发布默认的dropout开启模式，六次配置对照一致。

旋转输入编码在论文配置为 `(x,y,1000*cos(theta),1000*sin(theta))`，发布比例为500。该比例只在GT输入编码中明确应用；当前模型推理不输入GT动作，也没有将生成旋转向量投影到对应半径。因此，本轮不能声称独立验证了旋转训练比例的影响。

## 必须声明的重建假设

- 论文给出128步与初始时间1，没有给出完整生成网格及终点。本轮选取从1到0.01的128个等长区间，在左端点评分；0.01来自公开训练时间下限。这是实现选择。
- 论文没有明确后处理的梯度步长、精确交替顺序及停止容差。本轮使用单位排斥位移后按x/y压缩；运动不超过0.001、原生交叠为0且高度合法才记为原生收敛。达到100轮仍失败的候选保留。
- 凸多边形使用完整投影SAT最小分离位移；对凹多边形，先用真实轮廓交叠判定，再用边轴投影的保守位移代理。它不等于精确的非凸最小平移向量。旋转碰撞梯度未在论文中明确，本轮约束项只更新平移。
- 原生Clipper精度2保留，可能漏掉小交叠；参考几何另外计算所有候选。压缩保护也依赖此原生精度，不能将其“收敛”直接当作精确零交叠。
- 面积50沿用公开评价阈值。参考严格容差1e-9是本项目诊断约定，论文没有明确给出这个严格容差；不把它写成论文验收线。

## 仍无法对齐的材料

实际发布模型的参数总数与权重元素数均为 **10,621,276**；论文写约40M。发布模型没有单独的容器边界编码输入。直接替换网络维度会使当前权重不兼容，不能用随机新增参数充当论文训练结果。

固定训练源码的噪声下限及旋转训练比例与论文不同，现有权重的实际训练配置没有随权重提供。标准差还用于模型输出缩放，改变它会改变现有模型的分数，不能认为改推理参数便恢复了匹配训练的模型。公开Dental验证集是否等于论文测试集也未确认。

作者仓库在本轮检查时没有发布release条目；当前README仍指向已使用的资源包。获得论文对应架构、训练配置、匹配checkpoint和测试划分，是后续严格复现需要补齐的材料。当前证据不足以将差异唯一归因于权重。

下一步先补齐可核查材料：论文模型的构造参数及边界输入、匹配权重的训练噪声/动作尺度和损失配置、测试划分清单，以及非凸分离位移和后处理的伪代码。用这些材料固定一次匹配配置，再运行未参与调试的验证输入；材料未确认前，不通过扩大网络后随机初始化或反复调整现有权重的推理参数来声称论文复现。

## 实验与证据

本轮使用已经参与开发的样本0、45，每例512候选、128步、seed3407，三种配置共6次。它们是开发探针，不能作为独立泛化证据，也不能推算128例成绩或直接比较论文96.3%的候选可行率。

6组实验全部完成，运行失败0。`verify_paper_alignment.py` 校验通过：462个不同冻结输入、84个保存输出哈希，逐候选指标与汇总重算一致，另对三个阶段共48组代表候选重新计算几何。几何抽查不等于第二次重算全部候选；首次逐候选参考计算覆盖完整候选分母。`verified`只表示证据一致。18项公式、调度、边界与分母控制也通过。证据见 [验证摘要](paper_alignment/verification.json)、[计划](paper_alignment/plan.json) 和 [索引](paper_alignment/README.md)。

下面的可行数采用float64参考几何、最大两两交叠面积不超过50且位于高1200条带内；严格数采用本项目1e-9交叠和边界容差。每个配置的分母为两例各512，共1024：

- 发布采样器加统一新后处理：增强后 **23/1024** 可行（样本0为23、45为0），严格 **4/1024**；float32回写后为22和2。两例平均最佳条带利用率、无可行样本计零为37.9920%。
- 论文机制、发布噪声尺度：增强后 **265/1024** 可行（152、113），严格 **5/1024**（5、0）；float32回写后为238和1。两例平均最佳条带利用率为58.6503%。
- 完整论文数值设置：增强后 **4/1024** 可行（4、0），严格 **0/1024**；float32回写后为3和0。无可行样本计零的平均最佳条带利用率为30.7985%。

后处理不能视为已修复：发布采样配置全候选平均未阈值化两两交叠比例从0.4656%增至1.3489%，论文机制/发布尺度配置从0.1201%增至0.6124%。完整论文数值配置从2.7657%降至1.2186%，但仍有明显失败。可行候选增多不代表每个候选交叠都改善。三个配置的平均利用率也不能与历史76.80%的条件包围盒均值直接相比。

这组结果支持“不能把论文数值直接套到未确认训练配置的公开权重”，不证明权重是唯一根因。时间网格、非凸位移代理及后处理假设同样尚未排除。**不进入该重建版本的128例论文验收，也不宣称已恢复论文算法的全部细节。** 下一步先补齐对应模型/配置和约束细节，旧16例后处理消融保留为单独路线。

发布采样器的逐张量回归控制使用无填充输入，适用于本轮48件Dental布局；有填充行的通用输入不保证与上游保存的噪声逐位一致。后处理逐候选累计回滚数是实际接受/拒绝统计的依据，单步trace的回滚字段还包含对已收敛候选的计算检查。硬超时可能来不及生成最终元数据，校验器会保留该组512个未知候选并明确标注缺失的清单，不能将残留文件当作已测量成绩。

本地取回逐候选指标、动作、预览图及完整元数据，压缩包SHA256为 `a3adf4a2c413fdf9b968afbac719f91400864140f4fe0d5b872b646022d89072`；轨迹大文件保留在服务器并由原始清单绑定。源码/头文件快照见 [哈希清单](paper_alignment/source_sha256.json)。执行时复用了首轮 `run_inference.py` 辅助模块，与当前仓库的差异仅在未调用的 `parse_args` 和 `run` 两个入口函数；本轮导入的函数、依赖函数、常量及其他模块AST均一致，见 [版本核对](paper_alignment/helper_version.json) 及 [差异补丁](paper_alignment/helper_version.patch)。实际源文件哈希分别记录，不声称逐字节相同。原始动作、轨迹及含内部路径的元数据不进入Git。

## 运行方式

将本仓库脚本放在独立目录，`ROOT`为已准备的官方资源根目录；输出均须是不存在的新目录：

```bash
python build_collision_probe.py --source "$ROOT/upstream" --output "$ROOT/paper_build" --repair --paper-constraints
python check_paper_alignment.py --extension "$ROOT/paper_build" --upstream "$ROOT/upstream" --output "$ROOT/paper_controls.json"
python run_paper_suite.py --root "$ROOT" --extension "$ROOT/paper_build" --output "$ROOT/paper_probes"
python verify_paper_alignment.py --results "$ROOT/paper_probes" --output "$ROOT/paper_verification.json"
```

单例可用 `run_paper_alignment.py --root "$ROOT" --extension "$ROOT/paper_build" --output NEW_DIR --profile paper_settings --sample-index 0`。缩减候选只允许显式标记 `--smoke`，不得混入512候选结果。
