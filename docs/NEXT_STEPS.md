# 下一步规划：先验证碰撞消解，再决定优化与训练

状态：规划，以下实验均待执行。本轮仅编写文档。

## 当前依据与目标

官方默认模型模式的128例评测已完成，120例有官方有效候选，8例没有。有效样本平均最佳利用率76.80%，全部128例无有效候选计零为72.00%。剩余失败样本为25、45、46、47、54、62、99、115。

已检查的失败代表候选仍有局部碰撞；当前公开增强代码关闭了碰撞消解调用，只做缝隙压缩。原生几何计算还存在量化精度边界。因此，下一步先验证约束与后处理，不直接从头训练，也不把现有结果称为论文完整复现。

## 1. 固定对照材料和验收口径

- 保存第二轮计划、源码与权重哈希、汇总、完整性校验、候选及逐例诊断，保留第一轮eval基线。
- 将8例失败候选固定为首轮开发检查集；另外固定8例成功样本作为回归检查集：从成功样本按编号排序后，在等距位置取样，名单在修改前写入实验清单。
- 开发检查使用已保存的候选，不重新采样，避免把采样随机性当成后处理收益。两组开发样本不能再作为独立泛化证据。
- 官方有效性仍沿用面积阈值50；严格诊断仍使用float64参考几何和1e-9面积容差。两者分开报告，不放宽阈值。
- Dental条带高度按1200核查，记录最大高度、负坐标及越界量；利用率按相同包围盒口径计算。8000只是现有入口的参考宽度，不能以无限扩宽掩盖利用率损失。

交付：一份冻结实验清单，包含样本、候选索引、输入哈希、配置和原始指标。

## 2. 审查并单独验证碰撞消解函数

- 阅读`rm_overlap`的输入、终止条件、位移策略、边界处理、数值精度及线程行为；先确认是否适用于当前非凸多边形。
- 在独立源码副本和扩展目录构建，记录补丁与构建参数，不覆盖官方源码、现有扩展或旧结果。
- 先验证接触、浅交叠、明显交叠、凹多边形、靠近条带边界和原本无交叠六类小例子。设定最大迭代数与超时，保留未收敛和异常输出。
- 若现有函数不满足条件，先记录具体缺陷，再设计最小修正；不能仅取消注释就宣称恢复了论文算法。

通过条件：输出有限、零件数与刚体形状不变、不新增高度越界、碰撞量可解释且不恶化；每个小例子都有修改前后几何证据。未通过则停留在本阶段修正，不进入全量。

## 3. 用保存候选做后处理消融

在同一候选上分别运行：当前缝隙压缩、仅碰撞消解、碰撞消解后再压缩。每种路径使用独立输出，记录最终的候选，而不是把GT作为预测或重新选择采样结果。

- 对固定的8例失败与8例成功样本，比较官方有效性、最大/总两两交叠、严格零交叠、条带高度、利用率、位移与耗时。
- 对原始GT做控制：检查处理是否将原本可行布局变成碰撞或越界。
- 记录失败8例中修复多少，以及成功8例中退化多少；不把8例局部收益推广到128例。

阶段通过条件：至少修复1例失败样本的官方有效性，成功回归样本不丢失原有官方有效性，无新增高度越界或非有限输出。利用率与耗时变化逐例报告；这些条件只允许进入全量验证，不代表优化已交付。严格零交叠必须独立报告，未通过不能使用“完全无碰撞”的表述。

## 4. 分离验证微小交叠精度问题

- 在独立构建中检查Clipper坐标量化、压缩停止精度及输出float32转换的影响，一次只改变一个因素。
- 复用方形控制与原始GT，对照原生结果和float64参考几何，确认微小交叠是否实际减少。
- 若压缩阶段重新引入交叠，比较调整精度或增加最终消碰撞检查；每次都核查边界与利用率副作用。

通过条件：控制例与GT上的误差变化可复查，实际交叠减少；仅改变显示精度、阈值或把小交叠舍入成零不算修复。若1e-9无法可靠达到，明确报告残余，不事后修改通过标准。

- 保留无有效候选与执行失败样本，完整报告分母、候选有效率、样本成功数、两种利用率均值、边界与严格交叠结果、耗时。
- 比较120/128的官方模式基线，报告修复与退化的具体样本，避免只展示成功案例。
- 校验输入/输出哈希和汇总，保存补丁、命令、环境、图及失败记录。
- 整理课程报告：任务与方法、环境差异、原始基线、推理模式修正、后处理消融、局限与结论。开发用过的样本和验证集不包装成独立测试集；若提出泛化结论，另需未参与开发的数据。
