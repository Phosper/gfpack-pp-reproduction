# 第五轮证据索引

本目录只保存脱敏、可公开复核的轻量证据；按用户要求，本轮实际没有向GitHub发布。

- `build.json`：独立扩展构建、官方源文件哈希和新增头文件哈希。`iteration_limit=2000`是原函数插桩/第四轮修复入口的历史字段；本轮论文后处理上限由实验计划及逐例记录固定为100。
- `paper.patch`：在独立扩展增加论文平移场和缝隙压缩绑定；具体算法为仓库根目录 `paper_constraints.hpp`。
- `controls.json`：18项公式、符号、调度、边界及候选分母控制结果。只验证这些性质，不证明模型达到论文效果。
- `source_sha256.json`：本轮提供的11个脚本/头文件的逐字节哈希；实验实际冻结输入还包含官方源码、权重及数据，由私有完整清单记录。
- `plan.json`、`verification.json`：两例三配置的冻结计划、6组完整性校验、逐配置/逐阶段轻量指标及48组独立几何抽查。
- `helper_version.json`、`helper_version.patch`：服务器复用的辅助脚本与当前仓库之间的实际差异。仅未执行的两个入口定义不同，导入逻辑及常量AST一致；两种完整文件哈希分别记录。
- `local_readback.json`：本地取回包及78个可用输出哈希核对，6个轨迹文件留在服务器；同时核对30个跨运行源码绑定和辅助模块AST差异。

完整元数据、输入几何、动作和轨迹保存在本地私有证据目录；本目录不含账号、服务器信息、权重或完整数据。

几何评价中的“严格”采用本项目1e-9容差；原生Clipper精度2与官方面积50门槛单独保留。原生零交叠不能替代float64参考几何。
