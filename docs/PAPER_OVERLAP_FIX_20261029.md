# 论文复现为什么仍有交叠：本次排查与修正

日期：2026-10-29。工作分支：`codex/paper-reproduction`。

后续更新：已在用户资料目录找到完整第五轮回放包并核验真实候选；继续修正和结果见[第五轮真实候选继续排查](PAPER_ROUND5_CONTINUATION.md)。本页的四个工程坐标检查保留为历史证据，不能替代后续真实paper_settings回放。

**目前的结论：第五轮代码实现了论文的主要流程，但凹形碰撞位移、碰撞数值判断和最终选优仍有不足。已经跑过“论文参数”不等于每个实现环节都正确，也不等于公开权重已经与这些参数匹配。此次沿论文的方法修正这些环节，不能提前承诺达到论文成绩。**

这里区分三件事：论文明确要求的方法、本项目补写的执行细节、真实数据上验证过的效果。局部测试通过不等于Dental完整评测通过。

## 论文明确要求什么

依据 [论文第4.3—4.4节](https://arxiv.org/html/2406.07579v2#S4.SS4) 和 [第5.2节](https://arxiv.org/html/2406.07579v2#S5.SS2)：

- 生成使用128步Euler–Maruyama；在第97—128步加入碰撞约束。
- 碰撞项使用面积权重和分离位移，目的是降低碰撞；SAT用于近似求解分离位移。
- 生成后继续进行碰撞修正，最多100轮或收敛；期间沿负x、负y方向二分搜索，压缩间隙。
- 每个输入生成多个候选，从无碰撞候选中选利用率最高者。

本次不通过更改扩散方程、增加采样步数、放宽交叠阈值或无限延长后处理来制造成功结果。高度1200、面积权重和后处理100轮上限保留。论文没有写清的数值约定仍需标明。

## 失败记录已经说明什么

重新读取用户提供的第五轮JSON包，`paper_settings` 的原重建后处理记录如下：

| 指标 | 样本0 | 样本45 |
| --- | ---: | ---: |
| 生成结束、进入后处理时的最大两两交叠面积 | 20248.03 | 63152.50 |
| 原后处理100轮结束时的最大两两交叠面积 | 26016.55 | 58720.34 |
| 后处理前的最大高度越界 | 49.13 | 119.93 |
| 后处理后的最大高度越界 | 80.49 | 198.45 |
| 达到100轮、仍未满足原生收敛条件的候选 | 511/512 | 512/512 |

面积单位是坐标单位的平方，不是百分比，也不能直接写为平方毫米。表中每个值都是512候选中的最大值；前后最大值可能属于不同候选，不能把它们解释成同一零件的运动轨迹。

队友后续固定候选回放的独立几何汇总中，这两例在`paper_settings`下，原重建策略与`guarded_backtracking`策略保存为float32后均没有严格有效候选，即均为0/1024。后者在这组配置中平均交叠还更大，因此本次没有把它重新设为主线。

这些是明显碰撞和越界，不只是保存时产生的微小误差。数据也不能支持“只要把候选数设成512就一定能复现”的说法。

## 本次重点修正的实现问题

### 1．凹形零件不能直接套用整个轮廓的凸形SAT位移

旧`paper_constraints.hpp`对凸形使用SAT；对凹形仍把整个轮廓投影到轴上，取保守分离位移。这个代理可能把凹槽视为被填满，需要移动很远才把投影分开，和真实轮廓所需的短距离分离不同。它有可能把原本局部的碰撞扩大成对周边零件的扰动。

这不是稀少路径：第五轮样本0、45进入后处理时，512候选合计分别有16468、19394对碰撞走了凹形代理。但是，现有汇总不能量化每次失败中有多少由它引起，不能据此声称已经找到唯一原因。

新`paper_sat`几何后端的修正方向是：凸形保留SAT；凹形先做凸分解，构造各凸块对应的平移碰撞区域，并求其并集的最近边界，以计算使真实轮廓分开的平移。保留原零件的形状、面积和旋转，不把凹形直接替换成凸包。

这用于补齐论文“分离位移”的执行环节；**凸分解与配置空间并集的具体实现是本项目的数值实现，不是作者确认过的原始源码。** 对单对零件求得分离位移，也不保证所有零件同时更新后，整个布局立刻无碰撞。

### 2．碰撞检测与压缩必须检查实际轮廓

旧原生碰撞计算使用Clipper精度2的量化几何。量化后测得0，不能代替保存坐标在独立几何下的0；第五轮已有候选被标为`native_converged`，但严格参考检查仍未通过。

新后端使用float64实际轮廓做碰撞判断；负x、负y二分压缩只提交经过可行性检查的位置，不能仅因为搜索区间已经很小就返回一个未验证的位置。它仍是论文描述的方向和二分压缩，不引入随机搬移、零件缩放或另一套排样搜索。

float64计算也有浮点误差，不是精确有理数几何。主输出保留后处理的float64坐标，另存float32并再次检查；不能把float64通过冒充float32通过。微小精度问题与前述大面积碰撞分开报告。

### 3．最终展示应从真正通过的候选中选

旧入口的预览来自float64结果，采用最大两两交叠面积不超过50的本地判据。因此有交叠的候选也可能出现在“通过该判据”的预览里。50是绝对面积，不是允许50%的重叠。

此次主结果从实际保存的float64坐标中，按项目严格几何判据选择最佳候选；也可显式指定`--result-dtype fp32`。两种精度分别检查、分别报告，不跨精度偷偷回退。没有通过者就报告“没有有效候选”，不拿第0号候选代替成功结果。宽阈值结果仅作为诊断保留。

本地真实坐标复查证明：样本46、83在float64中严格通过，转为float32后失效。因此默认保留计算结果的精度，避免交付时无必要地降精度；这改变的是主输出格式，交叠和边界阈值均未放宽。论文未规定后处理必须转存成float32，不能把本项目原来的float32诊断约定说成论文要求。仍同时公开float32下0/4通过的事实。

本项目严格检查使用的1e-9容差不是论文公开确认的作者阈值，不据此把论文表中的0.00%解释成无限精度下每一候选都绝对为0。

## 哪些流程保留，哪些仍是补写细节

- 采样仍保留论文的噪声设置、128步EM及末32步约束；约束位移仍乘`g²Δt`，不增加人为倍率。
- 原重建的单位碰撞更新和100轮预算保留；没有启用`guarded_backtracking`的碰撞缩步、三项非增接受和停滞提前终止规则。
- 旧原生几何通过`legacy_native`保留，用于在相同原始候选上对照，不能覆盖历史结果。
- 单位步长、碰撞修正和x/y压缩的精确交替顺序，以及停止容差，仍属于论文未锁定的重建约定。保留它们不意味着已证明与作者相同。

因此本次应称为“修正论文重建中的几何实现”，不能称为“已经找回作者原版”或“已完全复现”。

## 权重与论文参数仍需单独核实

公开权重的官方来源已经核对，但来源正确不等于其训练配置已经核对完成。固定官方`score_model.py`最后将网络输出除以噪声标准差；修改噪声配置不仅改采样步长，还会改变给定t下的模型输出。记录用GT旋转向量改成1000，也不代表权重已按1000训练。

第六轮已有受控去噪检查，详见[权重与尺度核对](CHECKPOINT_ALIGNMENT.md)。在匹配实际sigma、固定噪声的开发输入上，DSM全通道误差相对同噪声零score基线的比值为：

| 噪声下限 / 旋转编码 | 相对误差 |
| --- | ---: |
| 发布设置1 / 500 | 0.4652 |
| 论文设置0.1 / 1000 | 9.2830 |

这是去噪误差比，不是交叠率、利用率或成功率；两个开发样本不能代表整个数据集。它说明当前权重与输入尺度存在兼容性风险，不能证明权重的真实训练参数，也不能把所有碰撞归因于权重。

若要确认完整论文复现，还需匹配的训练配置、模型构造和权重证据。不能偷偷改回发布尺度后宣称已经对齐论文，也不能靠增加随机初始化层补足参数量。

## 下一次运行必须回答什么

优先对同一批第五轮原始候选做新旧几何后端回放，避免重新采样的随机变化掩盖后处理差异。然后再用新后端进行完整生成，检查生成阶段约束是否改善。

新回放工具需要原运行的`input_sample.json`、`input_geometry.json`、`predictions_raw.pt`、`raw_metrics.json`和`metadata.json`，不需要加载原Linux扩展。若原清单包含增强后tensor，工具也会校验并重算其几何以作对照。本地两个第五轮JSON包只有采样和后处理日志，没有候选坐标，不能用于重算该轮512候选。

每个候选应分别保留修正前、修正后、x压缩后、y压缩后及float32保存后的交叠面积、越界、跨度和利用率；对未通过者保留失败原因，不从分母中删除。保存全部512候选，不能只交最佳图片。

先检查样本0、45的相同原始候选，再检查未参与本轮修正的输入。小规模通过后再跑128例；在正式结果出来前，不把几何控制测试的通过数量写成真实样本成功率。

## 队友下一步运行命令

优先用第五轮完整原始候选做CPU回放，无需重新生成：

```bash
# SOURCE是第五轮paper_settings某个样本的原始输出文件夹，不是仅有日志的ZIP。
SOURCE=/实际路径/sample_000_paper_settings
python -u replay_paper_geometry.py --source-run "$SOURCE" \
  --output /新的输出路径/paper_sat_smoke8 --candidate-limit 8
```

这是明确标记的前8候选耗时/机制检查，不能写成512候选评测。检查耗时、逐轮交叠和失败类型后，在新输出目录省略`--candidate-limit`才是完整同候选回放。样本45用相同方式另跑。回放JSON通过`metadata.json`中的哈希绑定输入；不覆盖旧文件。

若要测试新几何约束同时进入生成和后处理，先在原GPU环境运行一个缩减候选的诊断：

```bash
ROOT=/实际资源根目录
python -u run_paper_alignment.py --root "$ROOT" --extension "$ROOT/paper_build" \
  --output "$ROOT/results/paper_sat_sample0_smoke8" --sample-index 0 \
  --profile paper_settings --geometry-backend paper_sat --post-policy legacy_unit \
  --post-iterations 100 --candidates 8 --smoke --result-dtype float64
```

实际正式b128/b512运行用相应候选数并去掉`--smoke`。当前仍使用已下载的公开权重；该命令不会让尚未核实的训练尺度/模型构造自动对齐。`selected_result.json`记录主输出精度及严格选优；float64和fp32指标文件都需保留。不要只交预览图，也不要只报数值检查PASS。
